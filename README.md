# Country Data CLI (Countries.dev API)

This command-line tool was built for Code the Dream's Python Advanced Pre-Work. 
It uses the Countries.dev API to fetch live country data and allows the user to 
filter countries by region, find the most populous country, or compare two 
countries side by side.

## Features
- Filter countries by region
- Find the most populous country
- Compare two countries
- Displays name, population, area, region, capital, and languages
- Handles errors and missing fields gracefully

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the program:
   python main.py

## API Used
Countries.dev  
https://countries.dev/docs
